# Stable production identities

No runtime identifier is renamed. Board IDs B/S/D/G/R/C/E are editorial shot
identities; `beat` is the screenplay beat, `scene` is the canonical context/node,
`camera` and `location` reference the existing production catalogues.

| Drawing name / plan mark | Existing actor identity | Reference |

| Mara / M | `actor.mara` | [Mara](../characters/MARA.md), [sheet](../characters/references/mara-v1.png) |

An absent actor is not a new identity; untreated/treated, manual/automatic,
carried, missing and terminal states belong to these same four actors.
Inserts depict Alex’s glove unless their notes explicitly identify Mara/Lea.
Cast labels/inset marks locate people; exact close-up eyelines and contacts are
proposals, not a claim of final rig alignment.

Location references remain `loc.aurora_corridor`, `loc.emergency_stores`,
`loc.dispatch_hall`, `loc.generator_annex`, `loc.radio_cabin`,
`loc.ridge_crossing`, `loc.rescue_cabin`, `loc.daylight_report`,
`loc.aurora_exterior`. See the [environment catalogue](../environments/README.md)
and [camera catalogue](../environments/CINEMATOGRAPHY.md).

The index retains existing `cam.*` and `shot.wide`, `shot.hall`,
`shot.controls`, `shot.starter` aliases. Three establishing compositions are
explicit proposals: `cam.corridor_establish`, `cam.stores_establish`,
`cam.generator_establish`. They add no protocol type, traversal or asset loader.
The generator prototype’s controls/starter views are staging references; its
restricted playable rule subset does not replace canonical full-story outcomes.
