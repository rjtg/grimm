## Function / source [C]

Canonical `generator`, screenplay G01–G08. Coil already running, 30 seconds
initially hidden; heat-pack buys one minute; repeated latch work or an insulated
lever opens starter access. Diagram/log knowledge permits de-icer isolation.
An unsafe or cold start can fail; real success restores heat/cancels deadline.
Mara can pull Alex back when access seals. Closing access does not stop a
running generator. Reuse the existing Bevy staging lessons without adopting its
prepared-route assumptions or protected late start.

## Rule-sensitive variants [C→A]

Liner affects rates, heat pack extends the running timer, latch progress persists,
wrong de-icer path overloads, numb grip can fail, success locks the three startup
beats before releasing choices. A start selected late enough to be cut off
cannot produce a triumphant running engine. Exact completion at deadline and
selection at deadline are different source cases; no new timing rules here.
